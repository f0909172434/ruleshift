# Three-minute demonstration

1. **0:00–0:30 — Ask the question.** “If a rule changes, can the agent distinguish remembered evidence from current truth?” Open the homepage. Try the remembered decision, drag the blue policy ticket into the memory card, then try again. Move time to the restored rule to expose a false rejection. Explain that this first scene is a deterministic teaching illustration, not a model run.
2. **0:30–1:15 — Make the world change.** Start recurring rules, read the returns policy, refund and close task one. Use the clearly labeled privileged reference for tasks two and three. Advance to task four: the policy becomes 14 days while memory still says 30. This demonstrates the world, not model intelligence.
3. **1:15–2:15 — Inspect a real model run.** Open model replay. Name the model, split and completed denominator. Compare two strategies on the same schedule/seed/task. Expand tool events and point to actual state effects and costs. Show a failure as well as a success; do not substitute reference runs.
4. **2:15–3:00 — Explain what the evidence proves.** Replay verification reconstructs the same world. The score requires correct state and decision. Close with the measured tradeoff from the report and one limitation: a short synthetic single-model pilot cannot establish real-world generalization.

For a reviewer, provide the frozen protocol, exact model revision, result matrix, failed cases, release checksum and one-command evidence audit. Avoid implying that a public demonstration is an authenticated or sandboxed production service. The static hosted site is replay-only; interactive world actions require the loopback local server.
