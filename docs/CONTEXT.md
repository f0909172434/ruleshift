## 招聘訊息的範圍

2026-09-20 讀取 [DeepSeek 官方人才頁](https://talent.deepseek.com/)，頁面內資料標示擷取時間 2026-09-17，包含 **34 個不同職缺／團隊項目**。這不等於 34 人，也不表示每個項目均有相同名額。

完整項目與直接來源見 [JOBS.md](JOBS.md)。

## 最相關的能力對應

| 官方方向 | 可用 RuleShift 展示的證據 | 尚未證明的能力 |
|---|---|---|
| [Agent Harness 團隊](https://app.mokahr.com/social-recruitment/high-flyer/140576#/job/8d40c764-d2b2-49b1-826c-e3f2adb75c01) | 工具介面、記憶策略、可重播軌跡、獨立評分、失敗診斷 | 大規模真實使用者 Agent 的穩定性 |

| [Agent 彈性計算](https://app.mokahr.com/social-recruitment/high-flyer/140576#/job/bae809fb-1978-4401-b209-34067b26569d) | 工作單元切分、預算、可恢復任務、成本量測 | 真正隔離的執行環境、分散式排程、彈性伸縮 |
| 測試開發 | 狀態不變量、故障注入、輸入邊界、整批證據稽核 | 真實服務壓力與跨平台運維經驗 |
| Frontier／持續學習研究 | 明確假設、配對控制、規則改變、保留未受影響能力、負面結果 | 權重更新的持續學習、研究新穎性或頂會水準 |
| 前端／客戶端 | 以世界規則與記憶差異為中心的互動研究工具 | 大型產品完整設計與跨端發布能力 |

適合的定位是「能建造並驗證研究工具的工程型研究者」。一個小而完整、結果可追查的研究平台，比在筆電上假裝訓練巨型模型更能留下可評估的工作證據。

## 與既有研究的關係

| 參考工作 | 借鑑或需區別的部分 |
|---|---|
| [LifelongAgentBench](https://arxiv.org/abs/2505.11942) | 跨任務經驗累積；RuleShift 的焦點較窄，是固定權重 Agent 在短時程規則變更下的記憶策略。 |
| [ELL-StuLife](https://github.com/ECNU-ICALK/ELL-StuLife) | 持續虛擬世界與長期 Agent；本專案的零售狀態與任務範圍更小。 |
| [ToolSandbox](https://github.com/apple-aiml-research/ToolSandbox) | 有狀態工具使用與客觀評估；不能聲稱這些基本設計是本專案首創。 |
| [TimeWarp](https://github.com/sparklabutah/timewarp) | 介面隨時間變動；本實驗改變業務語義，工具名稱與格式固定。 |
| [ContDa](https://aclanthology.org/2026.findings-acl.1082/) | 對工具文件變化的持續適應；需區分文件／工具變動與此處由世界強制執行的規則變動。 |
| [SEAGym](https://arxiv.org/abs/2606.17546) | Harness 演化評估；本版只比較五個固定記憶策略，沒有自動演化整個 Harness。 |

這份比較是定位與後續閱讀入口，不是完整文獻綜述。尚未做外部基準的等預算重現，因此不主張超越以上工作，也不宣稱首次提出「改變規則的 Agent 世界」。

## 下一步的取捨

先把小世界的可驗證性做好，再選一個具有可測假設的擴充：例如查證價值估計、具有反例的記憶失效偵測，或規則變動頻率未知時的策略。大規模算子、通訊與分散式訓練也是職缺方向，但本專案不會假裝證明那些能力。
