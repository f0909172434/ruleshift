# Experience design

Core concept: A field notebook from a world whose rules move beneath its inhabitants. The timeline is the instrument: move through time to compare the policy in force, the agent's remembered evidence and the resulting action. Amber marks change; ink marks observation; vermilion marks a mismatch. The visitor can operate the world, then inspect actual recorded model runs.

Visitor path: understand the 30-day/14-day example → operate a shop task → advance simulated time → observe rule changes → inspect real model decisions → read methods and download evidence.

Visual principles: warm off-white paper, dark ink, restrained orange, serif display headlines with monospace metadata. A large horizontal phase rail is the core interactive device. Selecting an episode updates the policy sheet, the order and the event transcript together. Focus, selection and loading have visible feedback. No looping decorative animation; reduced-motion disables rail and panel transitions.

Decisions: no 3D scene because this experiment concerns semantic rules; no floating KPI-card wall because success without denominators is misleading; no fabricated agent animation because the trace must correspond to executed actions. The three-part sequence (old policy → changed rule → adaptation/failed adaptation) is replayed from saved evidence, not choreographed to imply a result.

Desktop uses an editorial two-column workbench; mobile uses one column with a scrollable timeline and clearly labelled controls. Core controls work with keyboard and expose live status. A static export keeps recorded experiments explorable without a server; live operations require the local service.
